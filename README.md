# Elektrický Rejnok – Dashboard (Vite + React + TypeScript + Tailwind)

## Rychlé spuštění
```bash
npm install
npm run dev
```
Aplikace poběží na URL, kterou vypíše Vite (typicky `http://localhost:5173`).

## Build
```bash
npm run build
npm run preview
```

## Co je uvnitř
- React 18 + TypeScript
- Tailwind CSS (třídy jsou už v komponentě použité)
- Recharts (grafy) a `lucide-react` (ikonky)
- Váš komponent: `src/ElectronicsKitDashboard.tsx`
